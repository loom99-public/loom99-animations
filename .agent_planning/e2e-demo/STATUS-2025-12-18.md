## Demo Patch Structure

```json
{
  "version": 2,
  "blocks": [
    {
      "id": "block-1",
      "type": "GridPoints",
      "params": { "count": 25, "rows": 5, "cols": 5, "spacing": 60, ... }
    },
    {
      "id": "block-2",
      "type": "PhaseClock",
      "params": { "duration": 2, "mode": "loop", ... }
    },
    {
      "id": "block-3",
      "type": "DotsRenderer",
      "params": { "minSize": 8, "sizeRange": 5, "color": "#00ccff", "glow": true, ... }
    }
  ],
  "connections": [
    { "from": { "blockId": "block-1", "slotId": "domain" }, "to": { "blockId": "block-3", "slotId": "domain" } },
    { "from": { "blockId": "block-1", "slotId": "positions" }, "to": { "blockId": "block-3", "slotId": "positions" } }
  ],
  "buses": [
    { "id": "bus-phaseA", "name": "phaseA", "type": { "world": "signal", "domain": "phase", ... } }
  ],
  "publishers": [
    { "busId": "bus-phaseA", "from": { "blockId": "block-2", "port": "phase" } }
  ],
  "listeners": [
    {
      "busId": "bus-phaseA",
      "to": { "blockId": "block-3", "port": "radius" },
      "lens": { "type": "ease", "params": { "easing": "easeInOutSine" } }
    }
  ]
}
```

## User Flow

1. Open editor at `http://localhost:5173/#/editor`
2. Click "Load Demo" button in top-right toolbar
3. See 3 blocks appear:
   - GridPoints in Fields lane
   - PhaseClock in Phase lane
   - DotsRenderer in Output lane
4. See connections: domain + positions wired
5. See bus indicator: PhaseClock → phaseA bus → DotsRenderer.radius (with breathing lens)
6. Preview shows: 25 dots in grid, smoothly growing/shrinking with easeInOutSine
