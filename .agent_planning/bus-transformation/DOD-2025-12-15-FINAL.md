# Definition of Done: Phase 1 Bus Transformation (FINAL)
Generated: 2025-12-15-FINAL

## Overview
These acceptance criteria define when Phase 1 of the bus transformation is complete. Phase 1 focuses on foundational data model and store management with a clean core/internal type split.

## P0: Bus Interface and Clean Type System
- [ ] **TypeDesc interface** with world ("signal" | "field" only), domain (core list), category ("core" | "internal"), busEligible
- [ ] **Core domains limited to**: number, vec2, color, boolean, time, phase, rate, trigger
- [ ] **Internal domains**: program, renderTree, scene*, wobble, jitter, wave, spiral, etc.
- [ ] **Bus interface** with id, name, type: TypeDesc, combineMode, defaultValue
- [ ] **6 standard combine modes**: sum, average, max, min, last, layer
- [ ] **Typed defaultValue** (JSON-serializable, time in SECONDS, no null for core)
- [ ] **sortKey property** for deterministic combine ordering
- [ ] **Three compatibility functions**: isDirectlyCompatible, getConvertiblePaths, isBusEligible
- [ ] **SlotType → TypeDesc mapping** with proper core/internal categorization
- [ ] **JSDoc documentation** for all interfaces
- [ ] **Lazy Field decision documented** for Phase 2

## P0: Routing Layer Architecture
- [ ] **BindingEndpoint type**: { blockId: string, port: string }
- [ ] **AdapterStep type**: { adapterId: string, params: Record<string, unknown> }
- [ ] **Publisher interface** with id(UUID), busId, from: BindingEndpoint, adapterChain?, enabled, weight?, sortKey
- [ ] **Listener interface** with id(UUID), busId, to: BindingEndpoint, adapterChain?, enabled
- [ ] **No bus properties on Slot** interface (routing separate from metadata)
- [ ] **Publisher sortKey** for deterministic combine order within each bus
- [ ] **Multiple publishers per output port** supported
- [ ] **UUID-based IDs** for stable references

## P0: Patch Structure Integration
- [ ] **buses: Bus[]** array in Patch interface
- [ ] **publishers: Publisher[]** array in Patch interface
- [ ] **listeners: Listener[]** array in Patch interface
- [ ] **schemaVersion: number** (increment from 1 to 2)
- [ ] **features: { buses: true }** for compatibility detection
- [ ] **toJSON()** includes all three arrays
- [ ] **loadPatch()** handles both v1 and v2 patches
- [ ] **Migration logic** converts v1 to v2 with empty arrays
- [ ] **Keep connections[]** array for backward compatibility

## P0: Store Management

- [ ] **@observable publishers** array in EditorStore

- [ ] **All arrays in makeObservable()** declarations
