### Why This Implementation Is Correct

1. **Absolute vs relative paths**: Using absolute paths (`/animations/`) is correct for Vite because:
   - Dev server serves from project root
   - Production dist/ is the server root
   - Relative paths (`../animations/`) break when React Router or nested routes change the base URL

2. **vite-plugin-static-copy choice**: Correct solution because:
   - Vite's public/ folder only works for files that don't need processing
   - Animations are outside gallery/ folder, need to be copied during build
   - Plugin is well-maintained and designed for this use case

3. **fs.allow configuration**: Correct for dev server to access parent directory animations without copying them during development.
