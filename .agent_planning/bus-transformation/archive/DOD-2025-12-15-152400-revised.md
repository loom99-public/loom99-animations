# Definition of Done: Phase 1 Bus Transformation (REVISED)
Generated: 2025-12-15-152400-rev

## Overview
These acceptance criteria define when Phase 1 of the bus transformation is complete. Phase 1 focuses on foundational data model and store management - no UI or compiler changes.

## P0: Bus Interface and Type System
- [ ] **TypeDesc interface** with world ("signal" | "field") and domain properties
- [ ] **Bus interface** with id, name, type: TypeDesc, combineMode, defaultValue
- [ ] **6 standard combine modes**: sum, average, max, min, last, layer
- [ ] **Typed defaultValue** (JSON-serializable, validated by domain, NOT any)
- [ ] **sortKey property** for deterministic combine ordering
- [ ] **TypeDesc mapping helpers** from existing SlotType for migration
- [ ] **JSDoc documentation** for all bus-related interfaces
- [ ] **Lazy Field evaluation decision** documented (Fields are functional, not arrays)

## P0: Routing Layer Architecture
- [ ] **BindingEndpoint type**: { blockId, port }
- [ ] **AdapterStep type**: { adapterId, params } (not any[])
- [ ] **Publisher interface** with id, busId, from: BindingEndpoint, adapterChain?, enabled, weight?, sortKey
- [ ] **Listener interface** with id, busId, to: BindingEndpoint, adapterChain?, enabled
- [ ] **No bus properties on Slot** interface (routing separate from metadata)
- [ ] **Publisher sortKey** for deterministic combine order within each bus
- [ ] **UUID-based IDs** for stable references
- [ ] **Multiple publishers per output port supported** (key architectural feature)

## P0: Patch Structure Integration
- [ ] **buses: Bus[]** array in Patch interface
- [ ] **publishers: Publisher[]** array in Patch interface
- [ ] **listeners: Listener[]** array in Patch interface
- [ ] **schemaVersion: number** (increment from 1 to 2)
- [ ] **features: { buses: true }** for compatibility detection
- [ ] **toJSON()** includes all three arrays
- [ ] **loadPatch()** handles both v1 and v2 patches
- [ ] **Migration logic** converts v1 to v2 with empty arrays

## P0: Store Management
- [ ] **@observable buses** array in EditorStore
- [ ] **@observable publishers** array in EditorStore
- [ ] **@observable listeners** array in EditorStore
- [ ] **All arrays in makeObservable()** declarations
- [ ] **Serialization support** in toJSON()
- [ ] **Deserialization support** in loadPatch()
- [ ] **clearPatch()** clears all arrays
- [ ] **getBusById()** computed property
- [ ] **getPublishersByBus()** and **getListenersByBus()** computed properties

## P0: Bus CRUD and Routing Operations
- [ ] **createBus(typeDesc, name?)** returns bus ID
- [ ] **deleteBus(busId)** cleans up routing references
- [ ] **updateBus(busId, updates)** modifies bus properties
- [ ] **addPublisher(busId, blockId, port, adapterChain?)** returns publisher ID
- [ ] **removePublisher(publisherId)** removes publisher
- [ ] **addListener(busId, blockId, port, adapterChain?)** returns listener ID
- [ ] **removeListener(listenerId)** removes listener
- [ ] **Type validation** for bus-slot compatibility
- [ ] **Wire coexistence** (no auto-deletion)

## P1: Routing Discovery and Inspection
- [ ] **getBusPublishers(busId)** returns Publisher[]
- [ ] **getBusListeners(busId)** returns Listener[]
- [ ] **getPortRouting(blockId, port)** returns {publishesAs?, listensTo?}
- [ ] **findBusesByType(typeDesc)** returns compatible buses
- [ ] **isBusBound(busId)** boolean check
- [ ] **getNextSortKey(busId)** for deterministic ordering

## P1: Type System Utilities
- [ ] **slotTypeToTypeDesc(slotType)** conversion helper
- [ ] **isTypeDescCompatible(a, b)** compatibility checker
- [ ] **validateDefaultValue(typeDesc, value)** validator
- [ ] **TypeDesc constants** for common domains
- [ ] **Adapter registry structure** (empty but ready)

## Hybrid Bus Creation Contract (Data Model Support)
- [ ] **No silent auto-creation** model encoded in data structures
- [ ] **Publisher creation intent** tracked (explicit vs gesture-based)
- [ ] **Bus name/type suggestions** stored for gesture-based creation
- [ ] **Create Bus button** support in store actions
- [ ] **Filtered bus selection** by TypeDesc compatibility

## Compiler Architecture Preparation (Phase 2 Readiness)
- [ ] **Publisher/Listener ready** to become graph edges
- [ ] **Bus nodes prepared** for first-class compilation
- [ ] **sortKey ordering** ready for deterministic combine
- [ ] **TypeDesc compatibility** ready for adapter validation

- No performance regressions in store operations
