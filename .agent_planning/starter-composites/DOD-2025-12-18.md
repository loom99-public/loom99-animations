# Definition of Done: Starter Composite Library

## Acceptance Criteria

### 1. New Primitives (3)
- [ ] **PositionMapLine** primitive exists with compiler
  - Takes Domain, outputs Field<vec2> of positions along a line
  - Parameters: a (start point), b (end point), distribution (even/random)
  - Test: produces correct positions for 5 elements

- [ ] **FieldMapVec2** primitive exists with compiler
  - Takes Field<vec2>, outputs transformed Field<vec2>
  - Supports: rotate, scale, translate, reflect operations
  - Test: rotation by 90 degrees produces correct output

- [ ] **TriggerOnWrap** primitive exists with compiler
  - Takes Signal<number> (phase), outputs trigger signal
  - Fires when phase wraps from ~1 back to ~0
  - Test: detects wrap at phase boundaries
