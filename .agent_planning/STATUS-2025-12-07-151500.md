**Impact**: Procedural/varied animations are broken - user cannot see new variations without full page reload.

**Files affected**: All 40 varied + procedural animation files

**Fix required**: Move random config generation inside `restart()` function OR create `regenerateParams()` function that recalculates all random values.

Example fix pattern:
```javascript
function generateConfig() {
    return {
        colors: {
            hueShift: Random.range(-60, 60),
            satShift: Random.range(-30, 30),
            // ... recalculate all random values
        }
    };
}

let config = generateConfig();  // Initial

function restart() {
    config = generateConfig();  // ← REGENERATE on each restart
    startTime = null;
    // ... reset animation state
}
```

### Priority 5: Add Exit Animations
**Impact**: Animations feel incomplete - only show "appearance" not full lifecycle.

**Design decisions needed**:
- Exit duration? (User says "quick")
- Exit timing? (User says "simultaneous" vs entrance "staggered")
- Exit effect? (Fade? Scale? Reverse entrance?)
- Auto-loop or manual restart only?

**Implementation approach**:
1. Add exit phase to animation timeline
2. Trigger exit after entrance completes + delay
3. All elements exit together with same duration
4. Simple fade + slight scale works universally

Example:
```javascript
const ENTRANCE_DURATION = 2000;
const HOLD_DURATION = 1000;
const EXIT_DURATION = 500;  // Quick!

// After entrance complete + hold
if (elapsed > ENTRANCE_DURATION + HOLD_DURATION) {
    const exitProgress = (elapsed - ENTRANCE_DURATION - HOLD_DURATION) / EXIT_DURATION;
    const exitEase = easeInQuad(exitProgress);  // Speed up going out

    // Apply to ALL elements simultaneously
    elements.forEach(el => {
        el.style.opacity = 1 - exitEase;
        el.style.transform = `scale(${1 - exitEase * 0.2})`;
    });
}
```
