## Root Cause Analysis

### The Problem
The gallery's preview feature uses relative paths that work in **development mode** (thanks to Vite dev server configuration allowing `..` access) but **completely fail in production/built mode**.

### Path Resolution Breakdown

**Development Mode (works)**:
```
Vite dev server runs from: gallery/
Browser loads: http://localhost:5173/
Iframe src: ../animations/logo/logo-01-line-drawing.html
Vite config (vite.config.ts:11): fs.allow: ['..']
Result: Vite serves files from parent directory ✅
```

**Production/Dist Mode (broken)**:
```
Built gallery at: gallery/dist/index.html
Iframe src: ../animations/logo/logo-01-line-drawing.html
Resolved path: gallery/animations/logo/logo-01-line-drawing.html
Actual path: animations/logo/logo-01-line-drawing.html (at root)
Result: 404 - Path does not exist ❌
```

### Why It Shows "Tiny Gallery"
When the iframe encounters a 404 or path resolution failure, the browser likely:
1. Falls back to loading the current page context (the gallery's index.html)
2. Renders the entire gallery React app inside the iframe
3. Results in a "tiny version of the gallery" appearing in the preview container
