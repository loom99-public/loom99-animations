## Current State: Player UI

**Structure:**

## What Must Change

### From Spec (PlayerTimeRootUI.md)

**Core Mandate**:
> "The UI is driven exclusively by CompiledProgram.timeModel (from the TimeRoot). No inference from PhaseClock. No heuristics. No player-side looping."

**Required:**
1. **Replace timeline scrubber** with a mode-switching Time Console
2. **Three distinct UI modes** based on `TimeModel.kind`:
   - `finite` → Bounded progress bar (start/end)
   - `cyclic` → Phase ring with period display
   - `infinite` → Sliding window scope
3. **Remove loop toggle** from player UI entirely
4. **Always-present controls**: Run/Freeze, Speed, Seed, Mode Badge
5. **TimeRoot picker** in editor header (separate from Time Console)

### Component Architecture

**New Components Needed:**
```
TimeConsole/
├── TimeConsole.tsx         # Container, mode switching
├── FiniteControls.tsx      # Bounded progress bar
├── CyclicControls.tsx      # Phase ring
├── InfiniteControls.tsx    # Sliding window scope
└── TimeConsole.css         # Mode-specific styles
```

**Modifications:**
- `PreviewPanel.tsx`: Replace scrubber row with `<TimeConsole />`, remove loop button
- `SettingsToolbar.tsx`: Add TimeRoot picker (or new EditorHeader)
- `Player.ts`: Remove `loopMode` property/methods (dependency on timemodel-types)

## UI Modes Breakdown

### Mode 1: FINITE
**Visual**: Bounded progress bar with start/end markers
**Controls**: Scrub (drag playhead), Jump to start/end
**Readouts**: `Time: 1.23s / 4.50s`, `Progress: 27%`
**Behavior**: Playhead stops at end, shows "ENDED" status

**Current Equivalent**: This is closest to current UI, but current UI shows this for ALL patches

### Mode 2: CYCLIC
**Visual**: Phase ring (circular scrubber)
**Controls**: Phase scrub (drag around ring), Period editor, Mode toggle (Loop/Pingpong)
**Readouts**: `Phase A: 0.37`, `Cycle #: 128`, wrap flash
**Behavior**: Continuous rotation, no "end"

**Current Equivalent**: None - completely new UI paradigm

### Mode 3: INFINITE
**Visual**: Sliding window scope strip
**Controls**: Window size editor, View scrub (shifts timeOffset)
**Readouts**: `Now: 12m 34s`, `View Offset: -2.3s`
**Behavior**: Window scrolls continuously, "now" at right edge

**Current Equivalent**: None - completely new UI paradigm

## Critical UI Principles (from Spec)

1. **Scrubbing never resets state** (Section 5.1)
   - Changes view transforms only (localT / phaseOffset / timeOffset)
   - Never reinitializes time mapping

2. **No loop toggle anywhere** (Section 5.3)
   - Looping is structural (CycleTimeRoot)
   - Player only: RUN/FREEZE, speed, dt scaling

3. **Mode badge is not decorative** (Section 1.5)
   - Always visible: FINITE / CYCLE / INFINITE
   - User's anchor for "what kind of thing am I building?"

4. **Structural changes require confirmation** (Section 5.2)
   - Changing TimeRoot kind/params → modal choice
   - Apply now / Apply on next wrap (cycle) / Apply when frozen
