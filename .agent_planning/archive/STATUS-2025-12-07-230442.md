## The Bug: Automatic Restart After Exit

### Expected Behavior
1. User clicks "Preview" button → div expands
2. Animation enters `entrance` state → animation renders
3. After entrance completes → enters `hold` state (2 seconds)
4. After hold timeout → enters `exit` state → exit animation plays
5. **After exit completes → STOP (idle/waiting state)**
6. Animation only restarts on user interaction (click) or new postMessage

### Actual Behavior
1. User clicks "Preview" button → div expands
2. Animation enters `entrance` state → animation renders
3. After entrance completes → enters `hold` state (2 seconds)
4. After hold timeout → enters `exit` state → exit animation plays
5. **After exit completes → `restart()` is called automatically**
6. Animation loops infinitely

### Root Cause

**The bug is in the exit animation completion logic.** When the exit animation reaches `progress >= 1`, all files call `restart()`:

```javascript
if (progress >= 1) {
    restart();  // ← BUG: Should enter 'waiting' state instead
}
```

This creates an infinite loop: `entrance → hold → exit → restart → entrance → ...`

## The Fix Required

### Changes Needed in Each File:

1. **Add 'waiting' state to initialization**
   ```javascript
   // BEFORE:
   let animationState = 'entrance';

   // AFTER:
   let animationState = 'waiting';
   ```

2. **After exit completes, transition to 'waiting' instead of restart**
   ```javascript
   // BEFORE:
   if (progress >= 1) {
       restart();
   }

   // AFTER:
   if (progress >= 1) {
       animationState = 'waiting';
       // Animation stops here, no more requestAnimationFrame calls
   }
   ```

3. **Update click handler to restart from 'waiting' state**
   ```javascript
   // BEFORE:
   document.body.addEventListener('click', () => {
       if (animationState === 'hold') {
           startExit();
       } else if (animationState === 'entrance') {
           restart();
       }
   });

   // AFTER:
   document.body.addEventListener('click', () => {
       if (animationState === 'hold') {
           startExit();
       } else if (animationState === 'entrance' || animationState === 'waiting') {
           restart();
       }
   });
   ```

4. **Update postMessage handler to restart from 'waiting' state**
   ```javascript
   // Most files already call startAnimation() or restart() in postMessage handler
   // This should work from 'waiting' state as well
   ```
