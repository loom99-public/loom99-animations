ALGORITHM IMPLEMENTED
--------------------
The PathMorphCompositor creates a "shoot-in-and-curve" effect:

1. Tail Interpolation:
   - Move command (M) position interpolates linearly from startPos to first point
   - At progress 0: tail at startPos
   - At progress 1: tail at first point

2. Body Morphing:
   - Each point morphs from "straight line position" to its final curved position
   - Straight line position: point lies on line from startPos to last point
   - At progress 0: all points collapsed onto straight line
   - At progress 1: all points at their final positions with curves
   - Intermediate: smooth interpolation

3. Command Types:
   - L (line): simple endpoint interpolation
   - Q (quadratic): interpolates both control point and endpoint
   - A (arc): interpolates radii and endpoint, preserves flags

4. SMIL Export:
   - Generates 11 keyframes (progress 0.0 to 1.0 in 0.1 steps)
   - Supports linear and spline easing modes
   - Produces valid <animate attributeName="d"> elements
