- [ ] Displays current time in format: `{X.XX}s` (two decimal places)

- [ ] Marker has class: `cue-marker` (can reuse from PreviewPanel.css)

- [ ] Markers do not obstruct scrubber interaction
- [ ] Renders correctly when `cuePoints.length === 0`

#### Visual Style
- [ ] Layout clearly shows bounded start → end structure
- [ ] Scrubber track visually distinct from infinite slider
- [ ] Start/end labels clearly readable
- [ ] Cue markers visible but subtle
- [ ] Matches PreviewPanel aesthetic (colors, fonts, spacing)

6. **Multiple Phase Lanes**: No secondary phase displays in Cyclic mode

These limitations should be **documented but not block sprint completion**.

## Rollback Plan

If critical issues arise during implementation:

1. **Partial rollback**: Keep TimeConsole, revert loop toggle removal if blocking
2. **Full rollback**: Revert all changes, restore original PreviewPanel scrubber
3. **Git tags**: Tag commits before major refactors for easy revert points

**Decision criteria for rollback**:
- Tests fail catastrophically (>50% failures)
- Build breaks with unfixable TypeScript errors
- User-facing crashes in editor (not just warnings)

**NOT rollback criteria**:
- Minor styling issues (can be fixed incrementally)
- Placeholder UI for Cyclic/Infinite (expected for this sprint)
- Missing nice-to-have features
