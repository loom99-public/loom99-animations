#### Technical Notes
**blocks.ts changes**:
```typescript
// BEFORE: Static options array

  {
    key: 'target',
    type: 'select',
    options: [
      { value: 'logo', label: 'Logo' },
      { value: 'text', label: 'Text' },
      { value: 'heart', label: 'Heart' },
    ],
  },
]

// AFTER: Dynamic options from library
import { pathLibrary } from './pathLibrary';

paramSchema: [
  {
    key: 'target',
    type: 'select',
    options: () => pathLibrary.getAll().map(entry => ({
      value: entry.id,
      label: entry.name,
    })),
    defaultValue: 'builtin:logo',
  },
]
```

**SVGPathSource.ts changes**:
```typescript
// BEFORE: Direct imports
import { LOGO_PATHS, TEXT_PATHS, HEART_PATHS } from '../../../../data/pathData';

compile({ params }) {
  const target = String(params.target ?? 'logo');
  const paths = target === 'text' ? TEXT_PATHS :
                target === 'heart' ? HEART_PATHS :
                LOGO_PATHS;
  // ...
}

// AFTER: Use PathLibrary
import { pathLibrary } from '../../../pathLibrary';

compile({ params }) {
  const targetId = String(params.target ?? 'builtin:logo');
  const entry = pathLibrary.getById(targetId);

  if (!entry) {
    console.warn(`Path not found: ${targetId}, falling back to logo`);
    entry = pathLibrary.getById('builtin:logo')!;
  }

  const paths = entry.data;
  // ... rest of sampling logic unchanged
}
```

```typescript
// Auto-migrate old target values

  if (oldValue === 'text') block.params.target = 'builtin:text';
  if (oldValue === 'heart') block.params.target = 'builtin:heart';
}
```

#### Technical Notes

```typescript
const handleExport = (entry: PathEntry) => {
  const json = pathLibrary.exportAsJSON(entry.id);
  if (!json) return;

  const blob = new Blob([json], { type: 'application/json' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `${entry.name.replace(/\s+/g, '-')}-${Date.now()}.json`;
  a.click();
  URL.revokeObjectURL(url);
};
```

```typescript
function generateThumbnail(data: LineData[], viewBox?: string): string {
  const vb = viewBox || '0 0 400 400';
  const pathStrings = data.map(line => lineDataToSVGPath(line));

  return `<svg viewBox="${vb}" xmlns="http://www.w3.org/2000/svg">
    ${pathStrings.map((d, i) =>
      `<path d="${d}" fill="none" stroke="${data[i].color}" stroke-width="2"/>`
    ).join('')}
  </svg>`;
}
```

### Category 2: Path Generation (Medium - Worth Exploring)

#### 2.1 Text-to-Path Converter
- **Input**: Text string + font family
- **Output**: LineData[] approximating text outline
- **Approach**:
  - Render text to canvas with `fillText()`
  - Use `getImageData()` to find edges
  - Trace edges with marching squares
  - Convert to LineData format
- **Complexity**: Medium (canvas API, edge detection)
- **Value**: High - instant custom text paths

#### 2.2 Shape Generators
- **Shapes**: Circle, rectangle, star, polygon, spiral, wave
- **UI**: Dropdown + parameter inputs (radius, points, etc.)
- **Implementation**: Parametric equations → PathPoint[]
- **Complexity**: Low-Medium (pure math)
- **Value**: Medium - useful for procedural shapes

#### 2.3 Icon Pack Integration
- **Source**: SVG icon libraries (Heroicons, Feather, etc.)
- **UI**: Browse icons in modal, click to add
- **Implementation**: Fetch SVG from CDN → parse → add to library
- **Complexity**: Medium (API integration)
- **Value**: High - instant professional icons

### Recommendation: Priority Order

**If doing ANY path editing, do these first (ranked by value/effort)**:
1. **Point Density Control** (trivial, immediately useful)
2. **Scale/Flip Transform** (easy, high value)
3. **Color Override** (trivial, high value)
4. **Shape Generators** (medium effort, medium value, enables procedural work)
5. **Text-to-Path** (medium effort, very high value IF it works well)
6. **SVG Optimizer Link** (trivial, helpful for imports)

**Definitely skip**:
- Point-level editing (too complex, external tools exist)
- Path combination (low value)
- Bounds crop (niche use case)

## Risk Assessment

### High-Risk Items
1. **Dynamic dropdown options in paramSchema** (UNKNOWN)
   - Current `paramSchema` is static object
   - Changing to function `options: () => PathEntry[]` may not be supported
   - **Mitigation**: Test with simple example first. If blocked, use MobX computed in Inspector.tsx to regenerate select options
   - **Fallback**: Store dropdown options in EditorStore, update on library changes

2. **MobX reactivity across service boundary** (MEDIUM)
   - PathLibrary is separate from EditorStore
   - Need to ensure dropdowns re-render when library changes
   - **Mitigation**: PathLibrary already uses `makeAutoObservable()`, should work
   - **Test**: Add/remove path and verify dropdown updates without manual refresh

### Medium-Risk Items
1. **SVG parser edge cases** (EXPECTED)
   - Real-world SVGs may use commands not yet supported
   - Parser is already implemented but untested on diverse inputs
   - **Mitigation**: Extensive error handling exists. Test with variety of SVGs early.

2. **Old patch migration** (LOW-MEDIUM)
   - Existing saved patches use old target values ('logo', 'text', 'heart')
   - Need migration or fallback logic
   - **Mitigation**: Simple string replacement in patch loader

### Low-Risk Items
1. **localStorage limits** (LOW)
   - Large SVGs could exceed 5MB localStorage limit
   - **Mitigation**: Warn user, offer to export oversized paths to file instead
