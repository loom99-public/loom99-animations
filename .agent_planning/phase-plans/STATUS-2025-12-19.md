## Phase 0: Lock Invariants - COMPLETE

**All core invariants are documented and enforced.**

### What's Implemented
- **TimeCtx contract**: Defined in `compiler/unified/TimeCtx.ts`
- **Signal vs Field distinction**: `ValueKind` enum with explicit worlds
- **Bus immutability**: Buses are read-only after creation (BusStore.ts)
- **Element Domain rules**: `ElementDomain` interface in types-bus.ts
- **State-only memory**: Explicit `StateBlock` registry

### Compiler Assertions
- `PortTypeMismatch` error for type violations
- `CycleDetected` via SCC detection
- Domain mismatch hard errors
- `MultipleWriters` error for bus conflicts

### Key Files
- `types.ts`: 925 lines (type system)
- `types-bus.ts`: 317 lines (bus extensions)
- `compile.ts`: 14,338 lines (validation)

## Phase 1: Bus-Aware Compiler Core - COMPLETE

**Full bus compilation pipeline implemented and tested.**

### What's Implemented
1. **Unified Dependency Graph** (`DependencyGraph.ts`)
   - BlockOut + BusValue nodes
   - Wire, Publisher, Listener edges
   - SCC detection for illegal cycles

2. **Bus System** (`types.ts`, `BusStore.ts`)
   - TypeDesc with world/domain/category
   - Combine modes: sum, average, max, min, last, layer
   - sortKey for deterministic ordering
   - 5 default buses: phaseA, phaseB, energy, pulse, palette

3. **Bus Compilation** (`compileBusAware.ts`)
   - Multi-pass: blocks → publishers → combine → listeners
   - Adapter chain application
   - Lens evaluation on listener side

4. **Lens System** (`lenses.ts`)
   - 7 types: ease, slew, quantize, scale, warp, broadcast, perElementOffset
   - 12 presets: breathing, bounce, elastic, etc.

5. **UI Components**
   - BusBoard.tsx, BusChannel.tsx, BusInspector.tsx
   - BusCreationDialog.tsx, BusPicker.tsx, BusViz.tsx

### Tests
- `bus-compilation.test.ts`: 8 tests
- `field-bus-compilation.test.ts`: 8 tests
- `bus-name-suggestion.test.ts`: 11 tests

## Phase 2: Lazy Field Foundation - COMPLETE

**FieldExpr DAG system fully implemented with lazy evaluation.**

### What's Implemented
1. **FieldExpr DAG** (`FieldExpr.ts`)
   - AST nodes: const, domain, source, map, zip, bus, adapter
   - Lazy description of computation (not eager arrays)

2. **Domain Abstraction** (`Domain.ts`)
   - Stable element IDs (not indices)
   - `ElementDomain` interface with getIds/getOrder
   - ArcLengthDomain for SVG paths
   - Domain owner registration

3. **Per-Element Evaluation**
   - Sink-driven materialization
   - Dense batch evaluation (no per-element closures)
   - Memoization cache per frame

4. **Domain-Centric Blocks** (`compiler/blocks/domain/`)
   - DomainN, PositionMapGrid/Circle/Line
   - FieldConstNumber/Color, FieldHash01ById
   - FieldMapNumber/Vec2, FieldZipNumber
   - RenderInstances2D, PhaseClock, TriggerOnWrap

### Tests
- `FieldExpr.test.ts`: 24 tests
- `Domain.test.ts`: 16 tests
- `domain-pipeline.test.ts`: 16 tests

## Phase 3: Phase & Loop Primitives - 80% COMPLETE

**Core phase primitives working, advanced operations needed.**

### What's Implemented
1. **Phase Primitives**
   - `PhaseMachine` block (entrance → hold → exit)
   - `LinearPhaseBlock.ts`: Linear phase wrapping
   - `PhaseClock`: Phase generator with duration/mode/offset

2. **State Accumulators**
   - `HistoryBlock`: Track value history
   - `IntegrateBlock`: Accumulate signals
   - `StateBlock` registry

3. **Cycle Operations**
   - `TriggerOnWrap`: Fire at phase boundaries
   - Per-element cycle indices

4. **Demo Patch** (`breathing-dots.json`)
   - Proves full system works end-to-end

### What's Missing
- **Phase warping blocks** (speed modulation within cycle)
- **Multi-scale phase interactions** (nested phases)
- **Phase quantization blocks** (snap to steps)
- **Advanced fold operations**

### Tests
- `PhaseMachine.test.ts`: 23 tests
- `LinearPhase.test.ts`: 23 tests

## Phase 4: Runtime Safety & Live Editing - 30% COMPLETE

**Core player exists, hot-swap framework incomplete.**

### What's Implemented
1. **Player Architecture** (`runtime/player.ts`)
   - Single time source
   - Program hot-swap capability
   - Scrubbing support
   - Callbacks: onFrame, onStateChange, onTimeChange

2. **Timeline Hints**
   - TimelineHint with finite/infinite duration
   - CuePoint for markers

3. **Validation Framework**
   - Error decorations (`error-decorations.ts`)
   - Error code taxonomy

### What's Missing
- **Program compatibility signatures**
- **State mapping rules** (preserve state across swap)
- **Output crossfade fallback**
- **Error isolation** (one error shouldn't break all)
- **Zero-frame freeze guarantee**
