## Deliverable 1: Define TimeRoot Block Types

### Objective
Create block definitions for the three legal TimeRoot types per spec.

### Implementation

**File**: `gallery/src/editor/blocks/time-root.ts` (new file)

Define three primitive blocks:

1. **FiniteTimeRoot**
   - Category: 'TimeRoot'
   - Parameter: durationMs (number, 100-30000ms, default 5000)
   - Output: `systemTime: Signal<time>`
   - Output: `progress: Signal<number>` (0..1 clamped)
   - Color: '#ef4444' (red for finite)
   - Description: "Finite performance with known duration"

2. **CycleTimeRoot**
   - Category: 'TimeRoot'
   - Parameters:
     - periodMs (number, 100-10000ms, default 3000)
     - mode (select: 'loop' | 'pingpong', default 'loop')
   - Output: `systemTime: Signal<time>`
   - Output: `phaseA: Signal<phase>` (0..1 wrapped)
   - Color: '#3b82f6' (blue for cyclic)
   - Description: "Looping primary cycle"

3. **InfiniteTimeRoot**
   - Category: 'TimeRoot'
   - Parameter: windowMs (number, 1000-60000ms, default 10000)
   - Output: `systemTime: Signal<time>`
   - Color: '#8b5cf6' (purple for infinite)
   - Description: "Ambient, unbounded time (no primary cycle)"

## Deliverable 2: Compiler TimeRoot Validation

### Objective
Add compile-time validation that enforces "exactly one TimeRoot per patch" constraint.

### Implementation

**File**: `gallery/src/editor/compiler/compile.ts`

Add validation step in `compilePatchWireOnly()` (and `compileBusAwarePatch()` if needed):

```typescript
// After step 1 (validate block types exist)
// Before step 2 (build connection indices)

// Step 1.5: Validate TimeRoot constraint
const timeRootBlocks = Array.from(patch.blocks.values())
  .filter(b => {
    const blockDef = registry[b.type];
    return blockDef?.category === 'TimeRoot';
  });

if (timeRootBlocks.length === 0) {
  errors.push({
    code: 'MissingTimeRoot',
    message: 'Patch must contain exactly one TimeRoot block (FiniteTimeRoot, CycleTimeRoot, or InfiniteTimeRoot)',
  });
}

if (timeRootBlocks.length > 1) {
  errors.push({
    code: 'MultipleTimeRoots',
    message: `Patch contains ${timeRootBlocks.length} TimeRoot blocks - only one is allowed`,
    where: { blockIds: timeRootBlocks.map(b => b.id) },
  });
}

if (errors.length) return { ok: false, errors };
```

## Deliverable 3: TimeRoot Block Compilers

### Objective
Implement compiler functions that translate TimeRoot blocks into required output signals.

### Implementation

**File**: `gallery/src/editor/compiler/blocks/time-root.ts` (new file)

Create compiler functions for each TimeRoot type:

```typescript
export function compileFiniteTimeRoot(
  block: BlockInstance,
  inputs: InputArtifacts,
  ctx: CompileCtx
): OutputArtifacts {
  const durationMs = block.params.durationMs ?? 5000;
  const durationSec = durationMs / 1000;

  const systemTime: Signal<number> = (t: number) => t;
  const progress: Signal<number> = (t: number) =>
    Math.min(1.0, t / durationSec);

  return {
    systemTime: { kind: 'Signal<time>', signal: systemTime },
    progress: { kind: 'Signal<number>', signal: progress },
  };
}

export function compileCycleTimeRoot(
  block: BlockInstance,
  inputs: InputArtifacts,
  ctx: CompileCtx
): OutputArtifacts {
  const periodMs = block.params.periodMs ?? 3000;
  const periodSec = periodMs / 1000;
  const mode = block.params.mode ?? 'loop';

  const systemTime: Signal<number> = (t: number) => t;

  const phaseA: Signal<number> = (t: number) => {
    const cycles = t / periodSec;
    if (mode === 'loop') {
      return cycles - Math.floor(cycles); // 0..1 wrapped
    } else { // pingpong
      const phase = cycles - Math.floor(cycles);
      const cycleNum = Math.floor(cycles);
      return (cycleNum % 2 === 0) ? phase : (1 - phase);
    }
  };

  return {
    systemTime: { kind: 'Signal<time>', signal: systemTime },
    phaseA: { kind: 'Signal<phase>', signal: phaseA },
  };
}

export function compileInfiniteTimeRoot(
  block: BlockInstance,
  inputs: InputArtifacts,
  ctx: CompileCtx
): OutputArtifacts {
  const systemTime: Signal<number> = (t: number) => t;

  return {
    systemTime: { kind: 'Signal<time>', signal: systemTime },
  };
}
```

## Migration Notes

### Breaking Change
This introduces a **breaking constraint**: every patch must have exactly one TimeRoot.

### Backward Compatibility Strategy (Future)
Not in this sprint, but planned:
1. Auto-insert InfiniteTimeRoot for patches without TimeRoot (with warning)
2. Migrate PhaseMachine → FiniteTimeRoot when it's the only time block
3. Migrate PhaseClock with mode='loop' → CycleTimeRoot
4. Add "Fix Time Topology" button in error UI
