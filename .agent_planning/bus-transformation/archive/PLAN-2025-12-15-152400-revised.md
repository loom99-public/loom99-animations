## Executive Summary
Phase 1 establishes the foundational data model and store management for the bus-centric architecture. This sprint focuses on implementing the core Bus interface, a clean routing layer (Publisher/Listener), improved type descriptors (TypeDesc), and basic bus management functionality in the EditorStore.

**Critical Changes from Original Plan:**
1. **No bus properties on Slot** - routing is graph wiring, not port metadata
2. **Publisher/Listener routing layer** - explicit, inspectable routing fabric
3. **TypeDesc over SlotType** - richer type system for bus world
4. **Deterministic ordering** - sortKey for stable "last" combine mode
5. **Compiler-ready design** - buses as first-class nodes (compile when visited, not at end)
6. **Hybrid bus creation UX** - explicit creation with guided auto-creation from gestures
7. **Lazy Field evaluation** - Fields are functional (get(id) -> T), not arrays

The scope remains data model and store changes only - no UI or compiler updates included.

Total work items: 7 (P0: 5, P1: 2)

## Lazy Field Evaluation Decision (Phase 1)

**Critical Runtime Invariant**: Fields are functional, not arrays

**Definition**:
```typescript
// CORRECT: Lazy Field form
type Field<T> = {
  get: (id: string, time: number) => T;
  // No toArray() method at runtime
}

// WRONG: Array form - DO NOT USE
// Field<T> = T[]
```

**Data Model Implications**:
- Bus.defaultValue stores JSON-serializable values only
- Field buses will be compiled as wrapper fields, not materialized arrays
- TypeDesc.domain helps determine if bus carries Signal or Field values
- Compiler will combine fields by creating wrapper fields, not array operations

**Benefits**:
- Scales to thousands of elements without allocation
- Enables fusion/optimization in Phase 2 compiler
- Maintains per-element control for particle systems

## Appendix: Phase 2 Bus Runtime Evaluation Pseudocode

This section provides the implementable blueprint for Phase 2 compiler work.

### Definitions
```typescript
// Graph nodes
type BlockOutputKey = [blockId: string, outPort: string];
type BusKey = string; // busId

// Artifact types
type Artifact = Program<T> | Field<T> with { typeDesc: TypeDesc };

// Memory boundary blocks (feedback safe)
type MemoryBlock = 'DelayLine' | 'Integrate' | 'SampleHold' | ...;

// Adapter types
type AdapterStep = {
  adapterId: string;
  params: Record<string, any>
};
```

### Step A: Build Value Dependency Graph

**Graph Nodes**:
- `BlockOut(blockId, port)` - Represents block output artifacts
- `BusValue(busId)` - Represents compiled bus value

**Graph Edges**:
1. **Wire edges**: `BlockOut(A,out) → BlockNode(B)`
2. **Publisher edges**: `BlockOut(A,out) → BusValue(busId)`
3. **Listener edges**: `BusValue(busId) → BlockNode(B)`
4. **Adapter param edges** (v2): `BusValue(paramBus) → adapter consumer`

### Step B: Validate Cycles with SCC Detection

```typescript
// Run Tarjan's algorithm on dependency graph
const sccs = tarjan(graphNodes);

for (const scc of sccs) {
  if (scc.size === 1 && !hasSelfLoop(scc)) continue;

  // Check if cycle is legal (crosses memory boundary)
  const hasMemoryBlock = scc.some(node =>
    node.type === 'BlockOut' && isMemoryBlock(node.blockId)
  );

  if (!hasMemoryBlock) {
    throw new Error(
      `Illegal feedback loop: ${[...scc].join(', ')} - requires Delay/Integrate`
    );
  }
}
```

### Step C: Stable Topological Sort

```typescript
const sortedNodes = topoSort(graphNodes);
// Stable tie-breaking:
sortedNodes.sort((a, b) => {
  const order = [nodeTypeOrder[a.type], nodeTypeOrder[b.type]];
  return order[0] - order[1] || a.id.localeCompare(b.id);
});
```

### Step D: Compile Artifacts in Topo Order

```typescript
const blockOutEnv = new Map<BlockOutputKey, Artifact>();
const busEnv = new Map<BusKey, Artifact>();
const publisherListsByBus = new Map<BusKey, Publisher[]>();

// Pre-sort publishers by sortKey
for (const pub of publishers) {
  const list = publisherListsByBus.get(pub.busId) || [];
  list.push(pub);
  list.sort((a, b) => a.sortKey - b.sortKey);
  publisherListsByBus.set(pub.busId, list);
}

for (const node of sortedNodes) {
  if (node.type === 'BlockOut') {
    // Compile block
    const inputs = resolveBlockInputs(node.blockId, blockOutEnv, busEnv);
    const outputs = compileBlock(node.blockId, inputs);

    for (const [port, artifact] of Object.entries(outputs)) {
      blockOutEnv.set([node.blockId, port], artifact);
    }
  } else if (node.type === 'BusValue') {
    // Compile bus immediately when visited
    const bus = buses.find(b => b.id === node.busId);
    const publisherArtifacts = [];

    for (const pub of publisherListsByBus.get(node.busId) || []) {
      if (!pub.enabled) continue;

      let artifact = blockOutEnv.get([pub.from.blockId, pub.from.port]);
      artifact = applyAdapterChain(artifact, pub.adapterChain);
      publisherArtifacts.push(artifact);
    }

    const busArtifact = combine(
      publisherArtifacts,
      bus.combineMode,
      bus.type,
      bus.defaultValue
    );

    busEnv.set(node.busId, busArtifact);
  }
}
```

### Step E: Runtime Evaluation (Per Frame)

**Signal Combine**:
```typescript
// Creates new program that combines publisher programs
function combineSignalPrograms(programs, combineMode) {
  return (time, ctx) => {
    const values = programs.map(p => p(time, ctx));
    return applyCombineMode(values, combineMode);
  };
}
```

**Field Combine (Lazy)**:
```typescript
// Creates wrapper field that combines on-demand
function combineFields(fields, combineMode) {
  return {
    get: (id, time) => {
      const values = fields.map(f => f.get(id, time));
      return applyCombineMode(values, combineMode);
    }
  };
}
```

**Adapter Chain Application**:
```typescript
function applyAdapterChain(artifact, chain, targetType) {
  let result = artifact;

  for (const step of chain) {
    const adapter = adapterRegistry.get(step.adapterId);
    result = adapter.apply(result, step.params);

    if (result.typeDesc.world !== targetType.world) {
      // This is a lift operation (e.g., Signal → Field)
      if (step.params.mode === 'broadcast') {
        result = createBroadcastField(result);
      } else if (step.params.mode === 'reduce') {
        result = createReduceProgram(result, step.params.aggregator);
      }
    }
  }

  return result;
}
```

**Performance Optimizations**:
- Per-frame memoization: `busValueMemo[(busId, frameId)]`
- Lazy field evaluation: compute only when get(id) is called
- Compile-time fusion: collapse nested field wrappers
