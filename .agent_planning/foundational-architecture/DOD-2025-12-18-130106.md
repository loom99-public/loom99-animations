### Deliverable 3: History State Block

#### Implementation
- [ ] File created: `gallery/src/editor/compiler/unified/blocks/HistoryBlock.ts`
- [ ] HistoryBlock implements StateBlock interface:
  - [ ] `type: 'History'`
  - [ ] `stateShape`: declares `buffer`, `writeIndex`, `frameCounter` fields
  - [ ] `scrubPolicy: 'hold'` (freeze during scrub)
- [ ] `initState()` implementation:
  - [ ] Allocates circular buffer of configured depth
  - [ ] Initializes writeIndex to 0
  - [ ] Initializes frameCounter to 0
  - [ ] Returns valid StateMemory with buffer array
- [ ] `updateState()` implementation:
  - [ ] Reads `input` from inputs record
  - [ ] Writes value to buffer at writeIndex
  - [ ] Advances writeIndex (circular wrap)
  - [ ] Increments frameCounter
  - [ ] Only updates when `ctx.mode === 'performance'`
  - [ ] Freezes buffer when `ctx.mode === 'scrub'`
- [ ] `computeOutputs()` implementation:
  - [ ] Returns buffer in chronological order (oldest to newest)
  - [ ] Returns `latest` value (most recent sample)
  - [ ] Does not modify state (read-only)
- [ ] Circular buffer logic:
  - [ ] Fixed-size array allocation (no growth)
  - [ ] Oldest values overwritten when full
  - [ ] Wrap-around at buffer end
- [ ] Configuration parameters supported:
  - [ ] `depth: number` - buffer size (default 10, max 100)
  - [ ] Parameter passed through initState
- [ ] Registration:
  - [ ] HistoryBlock registered in stateBlockRegistry on module load
