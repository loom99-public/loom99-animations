## Deliverable 1: Define TimeRoot Block Types

### Must Have
- [ ] File `gallery/src/editor/blocks/time-root.ts` created
- [ ] Three block definitions exist: FiniteTimeRoot, CycleTimeRoot, InfiniteTimeRoot
- [ ] Each block has category set to 'TimeRoot'
- [ ] Block exports added to `gallery/src/editor/blocks/index.ts`

### FiniteTimeRoot Block
- [ ] Parameter: `durationMs` (number, min=100, max=30000, default=5000)
- [ ] Output port: `systemTime` with type `Signal<time>`
- [ ] Output port: `progress` with type `Signal<number>`
- [ ] Color: '#ef4444' (red)
- [ ] Description: "Finite performance with known duration"

### CycleTimeRoot Block
- [ ] Parameter: `periodMs` (number, min=100, max=10000, default=3000)
- [ ] Parameter: `mode` (select, options=['loop', 'pingpong'], default='loop')
- [ ] Output port: `systemTime` with type `Signal<time>`
- [ ] Output port: `phaseA` with type `Signal<phase>`
- [ ] Color: '#3b82f6' (blue)
- [ ] Description: "Looping primary cycle"

### InfiniteTimeRoot Block
- [ ] Parameter: `windowMs` (number, min=1000, max=60000, default=10000)
- [ ] Output port: `systemTime` with type `Signal<time>`
- [ ] Color: '#8b5cf6' (purple)
- [ ] Description: "Ambient, unbounded time (no primary cycle)"

## Deliverable 3: TimeRoot Block Compilers

### Must Have
- [ ] File `gallery/src/editor/compiler/blocks/time-root.ts` created
- [ ] Three compiler functions implemented:
  - [ ] `compileFiniteTimeRoot()`
  - [ ] `compileCycleTimeRoot()`
  - [ ] `compileInfiniteTimeRoot()`
- [ ] Compilers registered in `gallery/src/editor/compiler/blocks/index.ts`

### FiniteTimeRoot Compiler
- [ ] Reads `durationMs` parameter, converts to seconds
- [ ] Outputs `systemTime: Signal<time>` (identity function: `t => t`)
- [ ] Outputs `progress: Signal<number>` (clamped: `t => min(1, t/duration)`)
- [ ] Signal artifacts have correct `kind` field
- [ ] Handles missing parameters with defaults

### CycleTimeRoot Compiler
- [ ] Reads `periodMs` and `mode` parameters
- [ ] Outputs `systemTime: Signal<time>` (identity function: `t => t`)
- [ ] Outputs `phaseA: Signal<phase>` with wrapping logic
- [ ] Loop mode: phase wraps at period (sawtooth wave)
- [ ] Pingpong mode: phase bounces 0→1→0 (triangle wave)
- [ ] Phase stays in [0,1] range for all time values
- [ ] Signal artifacts have correct `kind` field

### InfiniteTimeRoot Compiler
- [ ] Reads `windowMs` parameter (used for metadata, not signal logic)
- [ ] Outputs `systemTime: Signal<time>` (identity function: `t => t`)
- [ ] No other outputs required
- [ ] Signal artifacts have correct `kind` field

### Test Coverage
- [ ] File `gallery/src/editor/compiler/__tests__/timeroot-compilers.test.ts` created
- [ ] FiniteTimeRoot tests:
  - [ ] Outputs correct signal types
  - [ ] Progress is 0.0 at t=0
  - [ ] Progress is 0.5 at t=duration/2
  - [ ] Progress is 1.0 at t=duration
  - [ ] Progress stays 1.0 at t>duration (clamped)
- [ ] CycleTimeRoot tests (loop mode):
  - [ ] Outputs correct signal types
  - [ ] Phase is 0.0 at t=0
  - [ ] Phase is 0.5 at t=period/2
  - [ ] Phase is ~1.0 at t=period (wraps to 0)
  - [ ] Phase is 0.5 at t=period*1.5
  - [ ] Phase wraps correctly over multiple cycles
- [ ] CycleTimeRoot tests (pingpong mode):
  - [ ] Phase is 0.0 at t=0
  - [ ] Phase is 0.5 at t=period/2
  - [ ] Phase is ~1.0 at t=period
  - [ ] Phase is 0.5 at t=period*1.5 (descending)
  - [ ] Phase is 0.0 at t=period*2 (restart)
- [ ] InfiniteTimeRoot tests:
  - [ ] Outputs systemTime signal
  - [ ] systemTime is monotonic (always increasing)
  - [ ] No other outputs present
- [ ] All tests pass: `cd gallery && pnpm test timeroot-compilers.test.ts`
