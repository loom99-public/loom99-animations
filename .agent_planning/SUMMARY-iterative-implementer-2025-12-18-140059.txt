ARCHITECTURE HIGHLIGHTS
-----------------------

Pull-Based Evaluation Pipeline:
1. RuntimeAdapter.evaluate(tMs) creates TimeCtx
2. Clear outputs from previous frame
3. Evaluate nodes in dependency order (from evaluationOrder)
4. For each node:
   - Collect inputs from previous evaluations
   - Get state memory if state block
   - Call evaluator(inputs, state, ctx)
   - Store outputs for downstream nodes
5. Extract RenderTree from output block
6. Increment frame counter

State Block Pattern:
- initState(frame): Create initial StateMemory
- updateState(state, inputs, ctx): Mutate state in-place
- computeOutputs(state, inputs, ctx): Read-only, return outputs
- scrubPolicy: Defines behavior during scrub mode

Feature Flag System:
- useUnifiedCompiler: false (default) → legacy compiler
- useUnifiedCompiler: true → UnifiedCompiler + RuntimeAdapter
- No breaking changes to existing code
- Transparent fallback on errors
