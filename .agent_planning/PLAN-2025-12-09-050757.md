### P0-3: Implement PathMorphCompositor

**Status**: Not Started
**Complexity**: High
**Dependencies**: None (can develop in parallel with P0-2)
**Spec Reference**: gallery/README.md § Compositor Types (lines 60-63) • Original HTML: logo-01-line-drawing.html (lines 132-167)
**Status Reference**: STATUS-2025-12-09-050344.md § Runtime Assessment (lines 36-72), § Architecture Assessment (lines 331-376)

#### Description
Create PathMorphCompositor that interpolates path points from straight line to curved shape, implementing the "shoot-in-and-curve" effect from original HTML animations. This is THE core requirement - lines must shoot in from off-screen positions and morph from straight to curved during animation, not simply reveal via stroke-dashoffset.

#### Acceptance Criteria
- [ ] PathMorphCompositor class created in gallery/src/compositors/PathMorphCompositor.ts
- [ ] Constructor accepts: startPos {x, y}, points[] array, PathPoint type definitions
- [ ] update(progress: number) method returns interpolated SVG path 'd' string
- [ ] Correctly interpolates L (line), Q (quadratic curve), and A (arc) path commands
- [ ] Handles control points for quadratic curves (cx, cy)
- [ ] Handles arc parameters (rx, ry, rotation, largeArc, sweep)
- [ ] Visual output matches original HTML animation behavior (shoot-in-and-curve)
- [ ] toSMIL() method generates valid SMIL animation for path morphing
- [ ] TypeScript types exported for PathPoint, PathMorphConfig

#### Technical Notes
Reference original HTML implementation (logo-01-line-drawing.html, lines 132-167):

Algorithm:
1. **Tail position**: Interpolate from startPos to first point
   ```typescript
   const tailX = startX + (firstPoint.x - startX) * progress;
   const tailY = startY + (firstPoint.y - startY) * progress;
   ```

2. **Body morphing**: Each point interpolates from straight line to curved path
   ```typescript
   // Calculate straight line position (all points along start→end line)
   const straightX = startX + (finalPoint.x - startX) * t;
   const straightY = startY + (finalPoint.y - startY) * t;

   // Interpolate from straight to actual curved position
   const currentX = straightX + (point.x - straightX) * progress;
   const currentY = straightY + (point.y - straightY) * progress;
   ```

3. **Control point interpolation**: For Q commands, interpolate control points similarly

4. **Build path string**: Construct SVG path 'd' attribute with M, L, Q, A commands

Path morphing for SMIL export requires `<animate attributeName="d">` with values attribute containing keyframe path strings.

// OLD (wrong approach):
addLineDrawing(duration, delay, easing) {
  // Animates strokeDashoffset only
}

// NEW (correct approach):
addPathMorph(startPos, points, duration, delay, easing) {
  this.compositor = new PathMorphCompositor(startPos, points);
  this.addTrack('progress', new Track({ from: 0, to: 1, duration, delay, easing }));

update(elapsed: number) {
  const progress = this.trackGroup.getValue('progress', elapsed);
  if (progress !== undefined && this.compositor) {
    const pathD = this.compositor.update(progress);
    this.svgElement?.setAttribute('d', pathD);
  }
  // ... opacity, other properties
}

#### Technical Notes
Document key architectural decisions:

**When to use path morphing**:
- "Shoot-in-and-curve" effects where lines enter from off-screen and bend
- Logo animations with flowing, organic motion
- Any animation requiring point-by-point interpolation

**When to use stroke-dashoffset**:
- Simple line reveal effects
- Writing/drawing effects without morphing
- Performance-critical cases (stroke-dashoffset is cheaper)

**Compositor pattern**:
```markdown
### Using PathMorphCompositor

PathMorphCompositor interpolates path points from straight lines to curved shapes:

```typescript

line.addPathMorph(
  { x: -100, y: 100 },  // start position (off-screen)
  [
    { x: 40, y: 40 },    // first point
    { x: 40, y: 160 },   // second point
    { type: 'Q', cx: 70, cy: 150, x: 100, y: 160 } // curved point
  ],
  400,  // duration
  0,    // delay
  'easeOutCubic'
);
