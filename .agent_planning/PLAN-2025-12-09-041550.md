## P0-3: Implement Variance System in React Component

**Status**: Not Started
**Complexity**: Small
**Dependencies**: P0-2 (React component created)
**Spec Reference**: LineDrawingAnimation.ts variance levels • **Status Reference**: STATUS-2025-12-09-040626.md § Track System Animation Factories

### Description
Implement the three variance modes (original, varied, procedural) by passing configuration to the LineDrawingAnimation factory. Each variance mode creates different visual effects.

### Acceptance Criteria
- [ ] **Original**: Static config, identical on each restart
  - [ ] No randomization
  - [ ] Fixed durations, stagger, easing
- [ ] **Varied**: Randomize on each restart
  - [ ] Regenerate animation config on each `restart()`
  - [ ] Use variance parameters: duration ±20%, stagger ±30%
  - [ ] Random easing selection
- [ ] **Procedural**: Maximum variance
  - [ ] Regenerate config on restart
  - [ ] Use variance parameters: duration ±50%, stagger ±50%
  - [ ] Randomize element order
  - [ ] Random easing per element
- [ ] Variance prop controls which mode is used
- [ ] No configuration bleed between restarts

### Technical Notes
- Factory already implements variance logic in `getVarianceParams()`
- Original: Create animation once, reuse instance
- Varied/Procedural: Create NEW animation instance on each restart
- Store seed or config to ensure reproducibility for "original"

## P0-6: Verify Animation Lifecycle (No Infinite Loop)

**Status**: Not Started
**Complexity**: Small
**Dependencies**: P0-2, P0-5 (component created, metadata updated)
**Spec Reference**: README "Common Animation Patterns" • **Status Reference**: STATUS-2025-12-09-040626.md § Implementation Red Flags #3

### Description
Test the animation state machine to ensure it follows the correct lifecycle (entrance → hold → exit → waiting) without auto-restarting. This addresses the infinite loop bug that affected procedural HTML files.

### Acceptance Criteria
- [ ] Load Line Drawing animation in gallery
- [ ] Observe lifecycle:
  - [ ] entrance: Lines draw in (1000ms)
  - [ ] hold: Static display (2000ms)
  - [ ] exit: Fade out (250ms)
  - [ ] waiting: Static, no further animation
- [ ] Verify NO auto-restart after exit completes
- [ ] Click-to-restart triggers entrance state manually
- [ ] Test all 3 variance modes: original, varied, procedural
- [ ] No infinite requestAnimationFrame loops
- [ ] State transitions logged/verifiable

### Technical Notes
- This is the #1 bug from procedural HTML files
- Animation.exit() must complete then STOP, not call restart()
- Use state machine: 'entrance' | 'hold' | 'exit' | 'waiting'
- Only 'waiting' state allows restart
- Clear all timeouts and cancel RAF on state transition
