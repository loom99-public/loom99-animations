### Animation State Machine (VERIFIED VIA CODE INSPECTION)
| Flow Stage | Input | Process | Store | Retrieve | Display |
|------------|-------|---------|-------|----------|---------|
| Initialization | HTML load | Create SVG/Canvas | animationState = 'waiting' | N/A | Blank state |
| Entrance | Click/autostart | requestAnimationFrame | animationState = 'entrance' | timestamp, progress | Animate in |
| Hold | Entrance complete | setTimeout | animationState = 'hold' | HOLD_DURATION | Static display |
| Exit | Hold timeout | requestAnimationFrame | animationState = 'exit' | exitStartTime, exitProgress | Animate out |
| Waiting | Exit complete | **BUG: calls restart()** | **Should be 'waiting'** | N/A | Should be blank |

**Bug Location**: Line 426 in `logo-01-line-drawing-procedural.html` (and 19 other procedural files)

```javascript
// CURRENT (WRONG):
if (exitProgress < 1) {
    requestAnimationFrame(animate);
} else {
    restart();  // ❌ BUG: causes infinite loop
}

// SHOULD BE (FIXED):
if (exitProgress < 1) {
    requestAnimationFrame(animate);
} else {
    animationState = 'waiting';  // ✅ FIX: stop and wait for click
}
```

**Verified Fix**: `text-universal-paths.html` was recently fixed and now correctly transitions to 'waiting' state.

## LLM Blind Spot Findings

### ✅ Checked: Second Run / State Persistence
- **Good**: Original and varied variants correctly transition to 'waiting' after exit
- **Bad**: Procedural variants call `restart()` instead of transitioning to 'waiting'
- **Impact**: Animations loop infinitely, never truly complete

### ✅ Checked: Cleanup & Resources
- **Good**: `holdTimeout` is cleared in `restart()` function
- **Missing**: No cleanup for requestAnimationFrame IDs (could leak on rapid restarts)
- **Missing**: No event listener cleanup on page unload
- **Canvas animations**: No explicit cleanup for canvas particle arrays

### ✅ Checked: Error Handling
- **Missing**: No error handling if animation HTML file doesn't exist
- **Missing**: No fallback if CDN libraries (flubber.js, opentype.js) fail to load
- **Missing**: No validation of SVG path data before rendering
- **Impact**: Silent failures if paths malformed or resources unavailable

### ✅ Checked: Edge Cases
- **Zero duration**: Would cause `NaN` in progress calculation (not handled)
- **Empty paths**: Would cause rendering failures (not validated)
- **Rapid restarts**: Could cause race conditions between entrance/exit states
