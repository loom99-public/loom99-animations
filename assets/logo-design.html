loom99 Logo Design Reference

Design Notes

The loom99 logo is designed as clean, stroke-based typography optimized for animation. Each letter/number is a separate path that can be animated independently.

Color Palette

#00d4ff (cyan) to #7b2ff7 (purple) to #ff2d75 (pink)
Gradient creates visual flow across the logo.

Technical Details

  • ViewBox: 0 0 600 200
  • Stroke width: 12px
  • Stroke linecap/linejoin: round
  • Glow effect: drop-shadow filters
  • 6 separable elements: L, O, O, M, 9, 9

Animation Considerations

Each character is a simple path that can be:

  • Drawn with line animation (stroke-dasharray/offset)
  • Decomposed into particles
  • Morphed from other shapes
  • Transformed in 3D space
  • Revealed through masks
  • And more...
