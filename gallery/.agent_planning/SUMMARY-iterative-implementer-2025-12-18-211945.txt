## Technical Approach

The core challenge was that Fields are compile-time/per-element values, while
Signals are runtime-varying. To support bus-driven animation of radius:

- Modified RenderInstances2D to detect Signal:number artifacts at compile time
- When signal detected, store reference and sample it in renderFn (per-frame)
- Broadcast the sampled scalar value to all elements as constant array
- Maintains backward compatibility with Field<number> inputs

This enables the "binding phase produces pleasing motion immediately" goal
without requiring systemic changes to the Field type system.
